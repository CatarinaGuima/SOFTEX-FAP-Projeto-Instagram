# 📸 Projeto Instagram – Protótipo

Este projeto é um protótipo inspirado no Instagram, desenvolvido como parte do meu portfólio durante a Formação Acelerada em Programação pela Softex. O principal objetivo foi praticar o uso de tecnologias web modernas, como HTML semântico, CSS com variáveis personalizadas, TypeScript e bibliotecas para simulação de dados, em um layout semelhante ao de uma rede social real.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido com as seguintes tecnologias:

- ✅ **HTML5 Semântico**
- 🎨 **CSS3** com custom properties
- ⚙️ **JavaScript**
- 🧑‍💻 **TypeScript**
- 🆔 [`uuid`](https://www.npmjs.com/package/uuid) – Geração de IDs únicos
- 🧪 [`Faker-js`](https://fakerjs.dev/guide/) – Geração de usuários e conteúdos fictícios
- 🛠️ [Visual Studio Code](https://code.visualstudio.com/download) – Editor de código utilizado

## ⚙️ Como Executar Localmente

1. Clone o repositório:

```bash
git clone https://github.com/CatarinaGuima/SOFTEX-FAP-Projeto-Instagram.git
```

2. Acesse a pasta do projeto:

```bash
cd SOFTEX-FAP-Projeto-Instagram
```

3. Abra o arquivo `index.html` no seu navegador  
   ou utilize a extensão **Live Server** no VS Code para visualização em tempo real.
