# 📸 Projeto Instagram – Protótipo

Este projeto é um protótipo inspirado no Instagram, desenvolvido como parte do meu portfólio durante a formação em programação pela Softex. O objetivo principal foi praticar conceitos de HTML semântico, estilização com CSS moderno, uso de bibliotecas JavaScript e geração dinâmica de conteúdo.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido com as seguintes tecnologias e ferramentas:

- ✅ **HTML5 Semântico**
- 🎨 **CSS3** com variáveis personalizadas (`custom properties`)
- ⚙️ **JavaScript**
- 🧑‍💻 **TypeScript**
- 🆔 [`uuid`](https://www.npmjs.com/package/uuid) – Geração de IDs únicos
- 🔧 [`Faker-js`](https://fakerjs.dev/guide/) – Dados fictícios realistas
- 🛠️ [Visual Studio Code](https://code.visualstudio.com/download)
